# Baseline 2026-04-25 — Attention Is All You Need (6-question gold set)

First real measurement after the arXiv-paper fixture replaced the synthetic
3-page fixture. Establishes the number future changes are compared against.

## Setup

- PDF: `tests/fixtures/attention_is_all_you_need.pdf` (Vaswani et al. 2017, arXiv:1706.03762) — 15 pages as extracted by pypdf.
- Gold set: `tests/eval/gold.json` — 6 handcrafted questions with human-verified `relevant_pages` and `must_cite_page`.
- Embedder: `all-MiniLM-L6-v2` (ADR-0003 default).
- Answerer: `StubAnswerer` — measures retrieval + citation plumbing only.
- `top_k = 4` (Pipeline default).
- Command: `python scripts/run_eval.py`.

## Observations

- **recall@3 (0.833) is strong** — on 5/6 questions the gold-relevant page is in the top 3 retrieved. The default `top_k=4` is well calibrated.
- **recall@1 (0.583) is noticeably worse** — the top-1 retrieved page is correct on only 3.5/6 questions. The gap between R@1 and R@3 is the retrieval-layer uncertainty the answerer has to resolve.
- **Q1 (intro motivation) fails R@1** — the introduction is page 2 but MiniLM ranks a later discussion page higher because the question paraphrases the motivation heavily. Expected MiniLM weakness.
- **Q6 (Table 3 ablation) fails completely** — the retriever never surfaces page 9. The page is dominated by a table and has little prose matching the question's wording. This is exactly the failure mode ADR-0003 flagged as a candidate trigger for visual retrieval (ColPali, planned as a future ADR).

## Targets for next iterations

- **Any change that pushes recall@3 to ≥ 0.9** is a win worth a commit.
- **Fixing Q6 specifically** is the concrete trigger for introducing visual retrieval.
- **Citation faithfulness is currently capped at recall** because the stub cites whichever page came first in retrieval. The real Inference answerer will move faithfulness independently of recall — re-measure once `HFInferenceAnswerer` is the default path.
